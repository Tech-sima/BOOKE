# 🔍 Отладка ошибок оплаты

## Как проверить ошибку

1. **Откройте консоль браузера (F12)**
2. **Нажмите "Купить" на кейсе**
3. **Посмотрите сообщения в консоли**

## Возможные ошибки и решения

### Ошибка 401 (Unauthorized)
**Причина:** Неправильный токен бота
**Решение:** Проверьте токен в коде (`js/main.js`, строка ~4004)

### Ошибка 400 (Bad Request)
**Причина:** Некорректные данные для invoice
**Решение:** 
- Проверьте, что `starsPrice` = 1 (целое число)
- Проверьте формат `prices` (должен быть массив объектов)

### "Invoice link создан успешно, но окно не открывается"
**Причина:** Проблема с `webApp.openInvoice()`
**Решение:**
- Убедитесь, что игра запущена в Telegram Mini App
- Проверьте версию Telegram (нужна последняя)
- Попробуйте обновить приложение Telegram

### "Ошибка при оплате" после подтверждения
**Причина:** Проблема с обработкой успешного платежа
**Решение:**
- Проверьте консоль на наличие ошибок
- Убедитесь, что `handleSuccessfulCasePurchase()` вызывается

## Проверка кода

Убедитесь, что в `js/main.js`:

1. **Токен бота правильный:**
```javascript
const BOT_TOKEN = '8523928444:AAGYolZ4G3fqmjj2YYhyXJpjuFvq8dw_LsU';
```

2. **Цена кейса = 1:**
```javascript
starsPrice: 1
```

3. **Валюта XTR:**
```javascript
currency: 'XTR'
```

4. **provider_token пустой:**
```javascript
provider_token: ''
```

## Тестирование

1. Откройте игру в Telegram
2. Откройте консоль (F12)
3. Нажмите "Купить"
4. Смотрите сообщения в консоли:
   - "Invoice link создан успешно" - значит создание работает
   - "Открываем invoice в Mini App" - значит открытие началось
   - "Статус оплаты: paid" - значит оплата прошла

## Если ничего не помогает

Проверьте:
- ✅ Игра запущена в Telegram Mini App (не в браузере)
- ✅ Токен бота правильный
- ✅ Бот активен и работает
- ✅ Версия Telegram обновлена
- ✅ В консоли нет ошибок CORS или других
