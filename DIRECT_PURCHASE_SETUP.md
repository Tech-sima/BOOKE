# 🎮 Прямая покупка кейсов через Telegram Stars (без серверного бота)

## ✅ Что сделано

Система покупки настроена так, что:
1. Пользователь нажимает "Купить" в игре
2. Открывается окно Telegram с подтверждением оплаты
3. Пользователь подтверждает - звезды списываются
4. Награда автоматически выдается в игре

## 📋 Настройка (2 варианта)

### Вариант 1: С использованием PHP endpoint (РЕКОМЕНДУЕТСЯ)

1. **Загрузите файл `create_invoice.php` на ваш хостинг**
   - Файл должен быть доступен по HTTPS
   - Например: `https://yourdomain.com/create_invoice.php`

2. **Обновите URL в игре**
   - Откройте `js/main.js`
   - Найдите строку: `const INVOICE_ENDPOINT = 'create_invoice.php';`
   - Замените на полный URL: `const INVOICE_ENDPOINT = 'https://yourdomain.com/create_invoice.php';`

3. **Готово!** Покупки будут работать напрямую из игры.

### Вариант 2: Прямой вызов Bot API (без сервера)

Если у вас нет хостинга, код автоматически использует fallback - прямой вызов Bot API.

⚠️ **Внимание:** Токен бота будет в клиентском коде (небезопасно, но работает для тестирования).

## 🔧 Как это работает

1. **Пользователь нажимает "Купить"**
   - Игра отправляет запрос на создание invoice

2. **Telegram показывает окно подтверждения**
   - Пользователь видит сумму (1 звезда)
   - Нажимает "Оплатить"

3. **После успешной оплаты**
   - Telegram отправляет событие `invoice_closed` с статусом `paid`
   - Игра автоматически открывает кейс с наградой

## 🎯 Проверка работы

1. Откройте игру в Telegram Mini App
2. Перейдите в магазин
3. Нажмите "Купить" на любом кейсе
4. Должно открыться окно Telegram с подтверждением оплаты
5. После оплаты кейс автоматически откроется

## 🐛 Решение проблем

**Проблема:** Не открывается окно оплаты
- Проверьте, что игра запущена в Telegram Mini App
- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что endpoint доступен (если используете вариант 1)

**Проблема:** Платеж прошел, но кейс не открылся
- Проверьте консоль браузера
- Убедитесь, что событие `invoice_closed` обрабатывается
- Проверьте, что `initTelegramBotHandler()` вызывается при инициализации
